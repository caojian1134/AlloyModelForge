# AlloyModelForge native SQS v4: method and reporting contract

## Scope

The native optimizer constructs chemically decorated **initial atomistic
models** on geometry already generated by AlloyModelForge. It does not perform MD or
DFT relaxation and does not claim that a pair-optimized structure is an
equilibrium alloy. Its intended use is reproducible generation of bulk,
polycrystalline and spatially constrained starting configurations.

The optimizer preserves the exact integer element counts of every phase. Trial
moves are exchanges between unlike species, so phase composition cannot drift.
It minimizes a weighted sum of shell-resolved unordered-pair errors and optional
regional composition errors using simulated annealing. Every component is a
dimensionless mean squared relative residual, so a large region does not gain
weight merely because it contains more bonds. Reports retain the raw component,
explicit weight, weighted contribution and pair/site count.

## Finite-size random target

For a population of `N` sites containing `n_i` atoms of species `i`, native SQS
v4 uses sampling-without-replacement probabilities:

\[
p_{ii}=\frac{n_i(n_i-1)}{N(N-1)},\qquad
p_{ij}=\frac{2n_i n_j}{N(N-1)}\quad(i\ne j).
\]

Multiplication by the number of undirected bonds in a shell gives the expected
pair counts. This is the correct null model for a finite configuration whose
composition is fixed exactly. It avoids the small-cell bias introduced by the
thermodynamic-limit expressions `c_i^2` and `2c_i c_j`.

The conventional SRO report deliberately retains the thermodynamic-limit model
so that Warren-Cowley and external-backend comparisons remain conventional. The
JSON report labels these definitions as
`finite_fixed_composition_without_replacement` and
`thermodynamic_limit_random_alloy`; they must not be presented as the same
metric.

## Regional constraints

Each constraint may specify a target composition and two pair scopes:

- `internal`: count only bonds whose two endpoints lie in the region.
- `touching`: count each unique bond with at least one endpoint in the region.
- `crossing`: count bonds with exactly one endpoint in the region.

`touching` is useful for thin grain-boundary or interface selections, where an
internal-only graph can be sparse or empty. It is an undirected interfacial bond
definition, not a directional central-atom correlation. `crossing` isolates the
chemical contact across a selected region boundary, but remains undirected.

Before optimization the program reports the largest-remainder integer
composition target, unavoidable rounding L1 error, species availability, and
overlapping constraints that may conflict. A compact integer linear program
groups sites with identical region-membership signatures and proves whether all
integer regional compositions can be met simultaneously while preserving phase
composition. Availability-impossible requests are rejected; jointly impossible
requests can be rejected with `require_exact_region_composition: true`.

`target_pair_factors` expresses non-random pair propensities by shell. Factors
multiply finite-random unordered-pair targets and are renormalized to preserve
the shell's total bond count. For example, `Co-Ni: 2.0` favors Co-Ni relative to
the other pair classes. This is deliberately not labeled a directional
Warren-Cowley target; degree/composition realizability must be checked from the
reported residual.

## Search procedure

The proposal kernel mixes random unlike-species swaps with composition-directed
swaps. For the latter it exchanges an overrepresented species inside a region
with an underrepresented species outside it. All objective changes are computed
from affected bonds only.

The annealing temperature can adapt every 100 attempted moves toward a requested
acceptance rate. Runs may stop at an objective tolerance or after a configured
number of attempts without improvement. The historical best state, rather than
the terminal annealing state, is always returned. Reports include attempted and
accepted moves, acceptance rate, best step, stop reason and final temperature
factor.

`restarts` runs independent anneals from the same initial assignment with
recorded derived seeds. The best result is returned together with minimum,
mean, standard deviation and near-best fraction. This provides convergence
evidence rather than reporting a single favorable trajectory.

For explicitly small single-phase cells, `exact_benchmark_max_sites` enables
exhaustive enumeration of unique multiset permutations. A configuration-count
guard prevents accidental exponential work. The report gives the exact optimum,
degeneracy and absolute/relative optimality gap of the annealed result.

## Directional source-to-target SRO

Directional constraints construct oriented edges from a source selector to a
target selector. Both selectors must explicitly name phases, which freezes the
reference compositions to the phase compositions declared in the input. This
prevents the Warren-Cowley denominator and optimization target from drifting as
regional compositions change.

For source species `i` and target species `j`, the reported quantity is

\[
\alpha_{i\rightarrow j}^{A\rightarrow B}
=1-\frac{P(j\mid i,A\rightarrow B)}{c_j^B}.
\]

`A -> B` and `B -> A` are separate objectives. Target rows are renormalized so
their outgoing pair counts remain consistent with the source-species baseline.
The report includes oriented edge count, fixed reference compositions, achieved
regional compositions, directional pair counts, target counts, requested SRO
and achieved SRO. A low edge count limits realizability and must be reported.

## Restricted angular triplets

Triplet constraints are intentionally narrower than a crystallographic cluster
space. A selected center atom and every unordered pair of neighbors in one
requested shell define a motif. The neighbor vectors are evaluated with minimum
image convention and assigned to user-declared angle bins. Chemical keys retain
the center species and sort only the two neighbor species.

For center species `a` and unlike neighbor species `b,c`, the finite fixed-
composition null probability is

\[
P(a;b,c)=\frac{n_a\,2(n_b-\delta_{ab})(n_c-\delta_{ac})}
{N(N-1)(N-2)}.
\]

For equal neighbors, the neighbor term is a falling factorial. Targets are
multiplied by the number of geometric motifs in each angle bin. Accepted swaps
update only motifs touching either exchanged atom. Reports provide total and
per-angle-bin motif counts and residuals.

Optimization history is sampled every 100 steps by default to keep metadata
compact. Set `history_interval: 1` when a complete move-by-move trace is needed.

## Minimum evidence for publication

For every reported model, archive the input YAML, seed, software version,
structure fingerprint, pre/post objective, all shell-resolved SRO values,
feasibility report and optimization history. Report atom count, box, boundary
conditions, phase integer compositions, region definitions, neighbor-shell
construction, step budget and stopping rule. Use multiple independent seeds and
give distributions rather than only the best run.

Validation should include: exact composition conservation; determinism under a
fixed seed; objective improvement over random assignment; comparison with icet
or sqsgenerator on compatible periodic crystals; regional target residuals;
runtime and memory scaling; and visual inspection of spatial selections in
OVITO. Pair-only agreement must not be described as full cluster-correlation
agreement.

## Scientific limitations

Native SQS v4 optimizes unordered pairs, directional source-to-target pairs and
restricted angular triplets. It does not implement a symmetry-reduced general
cluster space, quadruplets, supercell-shape search, or prove a global
optimum for large systems, model chemical energetics, or impose diffusion
kinetics. Composition feasibility is proven, but pair-target realizability is
not yet solved as an integer quadratic feasibility problem.
These boundaries define a useful and testable contribution: constrained,
finite-size-aware SQS decoration of complex pre-built geometries.
